# Copeer

Единый настольный инструмент для Windows: **мультибуфер с историей + панель эмодзи и спецсимволов + скриншоты + переводчик**. Нативное WinForms-приложение на .NET 10 — без Electron, exe ~160 КБ, в трее, стартует мгновенно.

Название — от *clipboard + peer*: в roadmap — синхронизация буфера между устройствами (peer-to-peer).

---

## Возможности (MVP)

| Горячая клавиша | Действие |
|---|---|
| **Win+V** | Панель истории буфера: текст + изображения + **файлы из проводника**, поиск, Enter — вставить в прежнее окно, Del — удалить. История живёт между запусками (JSON + PNG в `%APPDATA%\Copeer`) |
| **Win+.** | Панель эмодзи и спецсимволов: поиск по-русски («сердце», «стрелка», «тире»…), категории, недавние — наверху. Клик — вставка в место курсора |
| **Win+Shift+S** | Свой оверлей скриншота: экран «замораживается», выделяешь область → снимок в буфере и в истории. Внизу всплывает плашка (фокус не забирает); если настроен OCR — на ней кнопка **«Распознать текст»**: текст → в буфер и в историю (движки: встроенный Windows OCR, офлайн; или Google Cloud Vision по ключу) |
| **Win+T** | Переводчик на [Neurooo API](https://neurooo.com/en/docs/api): открывается с текстом из буфера, авто-перевод, «Вставить в окно» вставляет результат туда, откуда вызвали |

Механика вставки — как у Ditto: содержимое кладётся в буфер, в целевое окно шлётся Ctrl+V, старое содержимое буфера возвращается обратно через 600 мс (настраивается). Если за это время пользователь успел скопировать что-то своё (любого типа), возврат не выполняется — проверка по счётчику изменений буфера.

### Перехват системных клавиш

- **Win+V** занимает через `RegisterHotKey` (системная история буфера Windows при этом не открывается — её место занимает Copeer). Если клавиша успел занять кто-то другой — её подхватывает тот же низкоуровневый хук.
- **Win+.**, **Win+Shift+S**, **Win+T** держит сама Windows (эмодзи-панель `TextInputHost`, «Ножницы», проводник), поэтому они перехватываются **низкоуровневым клавиатурным хуком** `WH_KEYBOARD_LL` — комбинация «глотается» до системной обработки (тот же приём, что в PowerToys Keyboard Manager).
- Если занятую через `RegisterHotKey` клавишу освободить (перезапуск Copeer), она перейдёт с хука на более надёжный механизм автоматически.

Выход: иконка в трее → правый клик → **Выход** (все клавиши возвращаются системе).

## Настройки

Трей → правый клик → **Настройки…** (хранятся в `%APPDATA%\Copeer\settings.json`):

- **Neurooo**: API-ключ (с кнопкой «Проверить» — тестовый запрос к API), язык перевода по умолчанию, движок (грузится из `/engines`)
- **История**: лимит записей, макс. длина текста, захват изображений и файлов (вкл/выкл)
- **Вставка**: задержка возврата старого буфера (мс), режим «оставлять вставленное в буфере»
- **Интерфейс**: позиция панелей (у курсора / по центру), тёмная/светлая тема
- **OCR**: движок распознавания текста на скриншотах — выключено / встроенный Windows OCR (офлайн, нужен языковой пакет в системе) / Google Cloud Vision (ключ из console.cloud.google.com, ~1000 запросов/мес бесплатно)
- **Система**: автозапуск с Windows (HKCU\...\Run)

## Neurooo: что выяснилось

Обёртка над сайтом не понадобилась — у Neurooo есть **официальный REST API v1** (запущен в июне 2025):

- `POST https://neurooo.com/api/v1/translate.json` — `{ "source": "...", "target_language_code": "ru", "source_language_code"?: "auto", "engine"?: "...", "tone"?: "formal|informal", "api_key": "..." }` → `{ "target": "...", "source_language_code": "en" }`
- также есть `detect_language`, `batch_translate`, `languages`, `engines`
- аутентификация: `api_key` в теле / `?api_key=` / заголовок `x-api-key`
- есть бесплатный тариф (Hobbyist); движки — модели OpenAI/Anthropic/DeepSeek

Готовых клиентов на GitHub нет (проверено) — клиент написан с нуля, см. `Core/NeuroooClient.cs`.

**Подключить ключ:** зарегистрируйтесь на neurooo.com → раздел [API](https://neurooo.com/en/api) → ключ впишите в `%APPDATA%\Copeer\settings.json`:

```json
{ "NeuroooApiKey": "ваш-ключ", "TargetLanguage": "ru" }
```

и перезапустите Copeer. Без ключа переводчик подскажет это в окне.

## Сборка и запуск

```bash
dotnet build -c Release                                # сборка
dotnet run -c Release                                  # запуск из исходников
dotnet publish -c Release -r win-x64 --self-contained false -o publish   # portable exe
```

Требуется Windows 10/11 и .NET 10 Desktop Runtime (для self-contained публикации рантайм не нужен: добавьте `--self-contained true`).

## Данные

Всё в `%APPDATA%\Copeer\`:

- `history.json` — история буфера (лимит настраивается, по умолчанию 500)
- `images\*.png` — скриншоты и картинки из буфера
- `settings.json` — ключ Neurooo, язык перевода, движок, лимит истории, недавние символы
- `copeer.log` — журнал (результаты захвата клавиш, ошибки)

## Архитектура

```
Program.cs            ApplicationContext: трей, маршрутизация хоткеев, чтение буфера, тема
Core/
  Native.cs           P/Invoke: RegisterHotKey, keybd_event, DWM и пр.
  HotkeyHost.cs       скрытое окно: WM_HOTKEY + WM_CLIPBOARDUPDATE
  KeyboardHook.cs     WH_KEYBOARD_LL: перехват Win+., Win+Shift+S, Win+T у самой системы
  ClipboardStore.cs   история (текст/изображения/файлы) + персистентность
  Paster.cs           вставка в прежнее окно: подмена буфера → Ctrl+V → возврат буфера
  Ocr.cs              распознавание текста на снимке: Windows OCR / Google Cloud Vision
  NeuroooClient.cs    клиент официального API Neurooo v1
  EmojiData.cs        офлайн-каталог эмодзи и спецсимволов с русскими ключевыми словами
  Theme.cs            палитра тёмной/светлой темы
  Langs.cs            список языков перевода
  Autostart.cs        автозапуск через HKCU\...\Run
  Settings.cs         модель настроек + журнал
UI/
  HistoryPanel.cs     всплывающая панель Win+V
  EmojiPanel.cs       всплывающая панель Win+.
  TranslatorForm.cs   окно Win+T
  SnipOverlay.cs      оверлей выделения области для Win+Shift+S
  SnipToast.cs        плашка после снимка (не забирает фокус) с кнопкой распознавания
  SettingsForm.cs     окно настроек
  Ui.cs               позиционирование панелей, фокус-хелперы
```

## Ограничения MVP

- Один инстанс
- Оверлей скриншота не оптимизирован под mixed-DPI мультимониторы (на однородных конфигурациях работает)
- Нет закреплённых/избранных записей истории

## Roadmap

1. **Синхронизация между устройствами** (главное для названия Copeer):
   - LAN peer-to-peer: UDP-discovery + TCP-передача записей, e2e-шифрование (TLS/Noise), разрешение конфликтов по времени;
   - опционально релей через свой VPS для «через интернет»;
   - телефон-компаньон через Telegram-бота как самый дешёвый мост (текст/фото → сразу в буфер ПК).
2. GIF-панель (Tenor/GIPHY API) рядом с эмодзи.
3. ~~OCR в скриншотах~~ — сделано (Windows OCR + Google Cloud Vision); осталось «перевести скриншот» одним нажатием.
4. Закреплённые записи, шаблоны текста.
5. Настройка хоткеев из UI, автозапуск, MSIX/portable-сборка с иконкой.
