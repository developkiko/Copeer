# Copeer

Единый настольный инструмент для Windows: **мультибуфер с историей + панель эмодзи и спецсимволов + скриншоты + переводчик**. Нативное WinForms-приложение на .NET 10 — без Electron, exe ~160 КБ, в трее, стартует мгновенно.

Название — от *clipboard + peer*: в roadmap — синхронизация буфера между устройствами (peer-to-peer).

---

## Возможности (MVP)

| Горячая клавиша | Действие |
|---|---|
| **Win+V** | Панель истории буфера: текст + изображения + **файлы из проводника**, поиск, мультивыделение Ctrl/Shift (Ctrl+A — всё), кнопки **Распознать** (для картинок) / **Перевести** / **Вставить** / **В файл** / **Отмена**. Мультивставка: тексты — через `\n`, картинки — через HTML (Word/браузер/мессенджеры вставят, не умеют — останется только текст). Панель перетаскивается за фоны строки поиска и кнопок. История живёт между запусками (JSON + PNG в `%APPDATA%\Copeer`) |
| **Win+.** | Панель с вкладками **Эмодзи / Символы / GIF**: поиск по-русски («сердце», «стрелка», «тире»…), категории, недавние — наверху. GIF — топ при входе на вкладку и поиск через Tenor (без своего API-ключа) с пагинацией; превью анимированные. Клик — вставка в место курсора |
| **Win+Shift+S** / **PrintScreen** | Свой оверлей скриншота: экран «замораживается», выделяешь область (размер в пикселях — на рамке) → **окно снимка** с кнопками **Распознать / Копировать / Вставить / Отмена**. Копирование и вставка кладут снимок в историю; Отмена отбрасывает. «Распознать» → окно распознавания: снимок + текст с кнопками **Копировать / Перевести / Вставить / В файл / Отмена** (движки: встроенный Windows OCR, офлайн; или Google Cloud Vision по ключу). PrintScreen перехватывается только «голый» — Alt+PrintScreen и прочие комбинации работают как в системе |
| **Win+Shift+W** | Переводчик на [Neurooo API](https://neurooo.com/en/docs/api): сначала забирает **выделенный текст** из активного окна (шлёт Ctrl+C; можно отключить в настройках), иначе — буфер обмена. Два селекта языка: исходный (по умолчанию — автоопределение) и язык перевода (запоминается), выбор движка. «Вставить в окно» вставляет результат туда, откуда вызвали. Кнопки: Копировать / Вставить / В файл / Отмена |

Кнопка **«В файл»** (история, распознавание, переводчик) — стандартный диалог Windows в режиме «All files»: расширение можно указать своё или не указывать. Текст пишется в выбранный файл; картинки и файловые записи из выделения сохраняются рядом: `<имя файла>-img1.png`, `<имя файла>-file1.ext`…

Механика вставки — как у Ditto: содержимое кладётся в буфер, в целевое окно шлётся Ctrl+V, старое содержимое буфера возвращается обратно через 1.5 с (настраивается). Если за это время пользователь успел скопировать что-то своё (любого типа), возврат не выполняется — проверка по счётчику изменений буфера.

### Перехват системных клавиш

- **Win+V** занимает через `RegisterHotKey` (системная история буфера Windows при этом не открывается — её место занимает Copeer). Если клавишу успел занять кто-то другой — её подхватывает тот же низкоуровневый хук.
- **Win+.**, **Win+Shift+S** держит сама Windows (эмодзи-панель `TextInputHost`, «Ножницы»), как и **Win+T** / **Win+Shift+T** (задачи панели задач) — поэтому эти комбинации перехватываются **низкоуровневым клавиатурным хуком** `WH_KEYBOARD_LL` — комбинация «глотается» до системной обработки (тот же приём, что в PowerToys Keyboard Manager). Переводчик потому и живёт на **Win+Shift+W**: клавиши с T Windows себе не отдаёт.
- **PrintScreen** перехватывается тем же хуком, но только «голый» — без модификаторов. Alt+PrintScreen, Win+PrintScreen и т.д. сохраняют нативное поведение.
- Если занятую через `RegisterHotKey` клавишу освободить (перезапуск Copeer), она перейдёт с хука на более надёжный механизм автоматически.

Выход: иконка в трее → правый клик → **Выход** (все клавиши возвращаются системе).

## Настройки

Трей → правый клик → **Настройки…** (хранятся в `%APPDATA%\Copeer\settings.json`):

- **Neurooo**: API-ключ (с кнопкой «Проверить» — тестовый запрос к API), язык перевода по умолчанию, движок (грузится из `/engines`)
- **История**: лимит записей, макс. длина текста, захват изображений и файлов (вкл/выкл)
- **Вставка**: задержка возврата старого буфера (мс), режим «оставлять вставленное в буфере»
- **Интерфейс**: позиция панелей (у курсора / по центру), тёмная/светлая тема
- **OCR**: движок распознавания текста на скриншотах — выключено / встроенный Windows OCR (офлайн, нужен языковой пакет в системе) / Google Cloud Vision (ключ из console.cloud.google.com, ~1000 запросов/мес бесплатно)
- **Панели**: режим скрытия панелей Win+V и Win+. — «сразу при потере фокуса» (по умолчанию) / «через N секунд» / «не скрывать (пока не закроют)»
- **Система**: автозапуск с Windows (HKCU\...\Run)

## Neurooo: что выяснилось

Обёртка над сайтом не понадобилась — у Neurooo есть **официальный REST API v1** (запущен в июне 2025):

- `POST https://neurooo.com/api/v1/translate.json` — `{ "source": "...", "target_language_code": "ru", "source_language_code"?: "auto", "engine"?: "...", "tone"?: "formal|informal", "api_key": "..." }` → `{ "target": "...", "source_language_code": "en" }`
- также есть `detect_language`, `batch_translate`, `languages`, `engines`
- аутентификация: `api_key` в теле / `?api_key=` / заголовок `x-api-key`
- есть бесплатный тариф (Hobbyist); движки — модели OpenAI/Anthropic/DeepSeek

Готовых клиентов на GitHub нет (проверено) — клиент написан с нуля, см. `Core/NeuroooClient.cs`.

**Подключить ключ:** зарегистрируйтесь на neurooo.com → раздел [API](https://neurooo.com/en/api) → ключ впишите в `%APPDATA%\Copeer\settings.json`:

```json
{ "NeuroooApiKey": "ваш-ключ", "TargetLanguage": "ru" }
```

и перезапустите Copeer. Без ключа переводчик подскажет это в окне.

## Сборка и запуск

```bash
dotnet build -c Release                                # сборка
dotnet run -c Release                                  # запуск из исходников
dotnet publish -c Release -r win-x64 --self-contained false -o publish   # portable exe
```

Требуется Windows 10/11 и .NET 10 Desktop Runtime (для self-contained публикации рантайм не нужен: добавьте `--self-contained true`).

## Данные

Всё в `%APPDATA%\Copeer\`:

- `history.json` — история буфера (лимит настраивается, по умолчанию 500)
- `images\*.png` — скриншоты и картинки из буфера
- `gifcache\*.gif` — кеш скачанных GIF (вставленных из панели Win+.)
- `settings.json` — ключ Neurooo, язык перевода, движок, лимит истории, недавние символы
- `copeer.log` — журнал (результаты захвата клавиш, ошибки)

  TranslatorForm.cs   окно Win+T

## Ограничения MVP

- Один инстанс
- Оверлей скриншота не оптимизирован под mixed-DPI мультимониторы (на однородных конфигурациях работает)
- Нет закреплённых/избранных записей истории

## Roadmap

1. **Синхронизация между устройствами** (главное для названия Copeer):
   - LAN peer-to-peer: UDP-discovery + TCP-передача записей, e2e-шифрование (TLS/Noise), разрешение конфликтов по времени;
   - опционально релей через свой VPS для «через интернет»;
   - телефон-компаньон через Telegram-бота как самый дешёвый мост (текст/фото → сразу в буфер ПК).
2. ~~GIF-панель~~ — сделано (вкладка GIF в панели Win+., Tenor без ключа); осталась подгрузка полной анимации прямо в превью.
3. ~~OCR в скриншотах~~ — сделано (Windows OCR + Google Cloud Vision + окно распознавания с кнопкой «Перевести»).
4. Закреплённые записи, шаблоны текста.
5. Настройка хоткеев из UI, MSIX/portable-сборка с иконкой.
